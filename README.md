# Arnab Ghosh

Full-stack and mobile developer based in Dhaka, Bangladesh. Computer Science and Engineering student at BRAC University.

I mostly build with Flutter and TypeScript/React, using Supabase and Firebase on the backend. Most of my projects are tools that fix everyday problems, especially for students.

### Tech

- **Languages:** Dart, TypeScript, Python, Swift
- **Frameworks:** Flutter, React
- **Backend and tools:** Supabase, Firebase, PostgreSQL, Docker, Vercel

### Projects

- **[RoutineBuzz](https://github.com/ags-arnab/routinebuzz-ui)**: Course schedule builder for BRAC University students. Search courses, build a weekly routine, share it with a link, and export it to a calendar. [Live site](https://routinebuzz.vercel.app)
- **[slApp](https://github.com/ags-arnab/slapp)**: Hands-free call control for motorcycle riders. A slap on the back of the phone silences or ends an incoming call.
